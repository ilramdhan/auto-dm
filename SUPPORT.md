# Support

- **Read first**: the [docs](docs/README.md), especially [meta-setup](docs/meta-setup.md), [docker](docs/docker.md) and [troubleshooting](docs/troubleshooting.md).
- **How-to questions**: ask in [Discussions, Q&A](https://github.com/ilramdhan/auto-reply-ig/discussions/categories/q-a). Ideas go to [Ideas](https://github.com/ilramdhan/auto-reply-ig/discussions/categories/ideas); share your setup in [Show and tell](https://github.com/ilramdhan/auto-reply-ig/discussions/categories/show-and-tell).
- **Stuck on setup or deployment**: open a [Setup / deployment help](https://github.com/ilramdhan/auto-reply-ig/issues/new?template=setup_help.yml) issue.
- **Instagram / Meta errors**: use the [Instagram / Meta API issue](https://github.com/ilramdhan/auto-reply-ig/issues/new?template=meta_api.yml) template.
- **Bugs / feature requests**: [open an issue](https://github.com/ilramdhan/auto-reply-ig/issues/new/choose).
- **Security**: see [SECURITY.md](SECURITY.md); do not post it publicly.
- **Contact**: me@ilramdhan.dev. This is a volunteer-run project, so replies may take a few days.

Never post access tokens, app secrets or full webhook payloads in public.
