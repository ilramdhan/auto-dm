# Support

- **How-to questions**: read the [docs](docs/README.md), especially [meta-setup](docs/meta-setup.md) and [troubleshooting](docs/troubleshooting.md), then ask in [GitHub Discussions](https://github.com/ilramdhan/auto-reply-ig/discussions) (or an issue if Discussions are off).
- **Bugs / feature requests**: [open an issue](https://github.com/ilramdhan/auto-reply-ig/issues/new/choose).
- **Security**: see [SECURITY.md](SECURITY.md); do not post it publicly.
- **Contact**: me@ilramdhan.dev. This is a volunteer-run project, so replies may take a few days.

Never post access tokens, app secrets or full webhook payloads in public.
